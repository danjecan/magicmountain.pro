# magicmountain.pro

Website for [Magic Mountain](https://magicmountain.pro): small-group guided hikes for adults and families, in English and Hungarian.

A static site generated by a small Python script (standard library only) and published with GitHub Pages.

```
python3 src/build.py                     # builds the site into ./dist
python3 -m http.server -d dist 8000      # preview at http://localhost:8000
```
