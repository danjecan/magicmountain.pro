## What this is
The live Magic Mountain website: bilingual (English/Hungarian) hiking trips run by Dan and Anett. It's a static site generated by Python and deployed to GitHub Pages at magicmountain.pro.
Repo: github.com/danjecan/magicmountain.pro (public) · Local: `~/Documents/Projects/magicmountain/magicmountain.pro`

**Read `README.md` first.** It covers the architecture, build and one-time setup.

## Related folders
- `../magic-mountain-design`: the design source (private repo). Design tokens and copy originate there; this repo ports them.
- `../brand`: logos and illustrations. `../content`: hike texts. `../trips`: trip photos. None of these are in git.
- Hike content lives in **Notion › Personal › Magic Mountain › Hikes** (this is the CMS). Don't hard-code hikes.

## Ground rules
- Python stdlib only. No pip dependencies, no JS framework. Build with `python3 src/build.py` (writes `dist/`), preview with `python3 -m http.server -d dist 8000`.
- All fixed copy lives in `src/content.py` as (English, Hungarian) pairs. Every change needs both languages.
- No secrets in the repo. Endpoints and tokens come from GitHub Actions secrets/variables (`NOTION_TOKEN`, `GAS_SIGNUP_URL`, `MAILCHIMP_*`).
- Copy rules: prices in HUF; one guiding+organisation price per person; never sell or show transport; say "small groups" without numbers; routes are "carefully chosen"; don't claim "no tourist trails".
- Brand colours: #FE6B00 orange, #001F61 navy, #00549F blue, #F5F5F5 off-white, #FFE9D9 peach.
- Keep the accessibility pass intact (contrast, touch targets, heading order, reduced motion).

## Git
